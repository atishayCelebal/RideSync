# RideSync - Intelligent Group Ride & Fleet Tracking Platform

## Overview
RideSync is a web-based platform designed to enhance the safety and coordination of group vehicle rides. The platform provides a real-time, map-based dashboard that leverages Artificial Intelligence to detect and alert group leaders to anomalous rider behavior.

## Features
- User and group management
- Secure API for GPS devices
- Real-time location streaming
- Interactive dashboard with Google Maps
- AI-powered anomaly detection

## Installation and Setup
1. Clone the repository: `git clone <repository-url>`
2. Navigate into the project directory: `cd ridesync`
3. Set up the database for production and development environments as per the configurations provided in `application.yml`.
4. Run the application using: `mvn spring-boot:run`
5. Access the application at `http://localhost:8080`.
